# 04 · 路线图

## 里程碑总览

```text
M0 规划 ──► M1 半双工闭环 ──► M2 全双工/打断 ──► M3 数字人 ──► M4 产品化
```

每个里程碑都以**可测量的验收标准**结束，不达标不进入下一个。

## M1 · 半双工语音闭环（2–3 周）

范围：按住说话 → ASR → LLM → TTS → 播放。**不做**数字人、不做打断。

- [ ] cpal 采集 + 48k→16k 重采样
- [ ] SenseVoice 整段识别（sherpa-onnx Rust）
- [ ] DeepSeek 流式调用 + 句子切分
- [ ] Piper 本地 TTS + 播放队列
- [ ] 最小 UI：按住说话按钮、字幕、状态指示
- [ ] 录音落盘开关（调试用，默认关）

**验收**

| 项 | 标准 |
|---|---|
| 首响 | ≤ 1.5 s（10 次中位数） |
| 字错率 | ≤ 5%（50 句测试集） |
| 稳定性 | 连续 10 轮不崩 |
| 资源 | 空闲内存 < 1.5 GB |

## M2 · 全双工与打断（2 周）

- [ ] VAD 常开，端点 600 ms 可调
- [ ] AEC（webrtc-audio-processing）+ 播放参考回灌
- [ ] barge-in：AEC 后人声 > 200 ms → 停播 + 取消 LLM + 清队列
- [ ] 状态机完整化，错误可恢复
- [ ] 音量自适应（外放时降低音量减少回声）

**验收**

| 项 | 标准 |
|---|---|
| 自打断误触发 | ≤ 1/20 轮（外放，正常音量） |
| 插话响应 | ≤ 300 ms 停止播放 |
| 静音回收 | 5 s 无语音回 Idle |

## M3 · 数字人（3–4 周）

- [ ] glTF 头部资产 + 12 个 blendshape
- [ ] 中文 viseme 映射表（拼音声母/韵母 → 口型）
- [ ] 音频驱动口型 + 平滑插值
- [ ] 表情状态机：中性 / 微笑 / 疑惑 / 思考 / 惊讶
- [ ] 眨眼、呼吸、轻微头部运动
- [ ] 打断时立即闭嘴并回 idle

**验收**

| 项 | 标准 |
|---|---|
| 帧率 | 720p 稳定 30 fps |
| 口型偏差 | ≤ 80 ms |
| 闭嘴延迟 | ≤ 100 ms |
| GPU 占用 | ≤ 50%（M1 Max） |

## 排期原则

1. **先窄后宽**：M1 只支持中文、只支持一个音色、只支持一个 LLM。
2. **数字人最后接**：它不改变核心链路，晚接不亏。
3. **每周一个可演示的东西**：哪怕只是"说一句话，屏幕出现文字"。
4. **不并行开三条线**：同一时间只推进一个里程碑。
